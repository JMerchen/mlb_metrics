Predictive Metrics Age Curves DFS Rankings

Today's hitters and probable starting pitchers, ranked by estimated DraftKings Classic MLB fantasy points. This is a ranked list of good plays, NOT a salary-cap lineup optimizer - no salary data is used anywhere on this page. Hitter points model hit-type scoring only (singles/doubles/triples/home runs, adjusted for today's actual opposing pitcher) - walks, HBP, runs, RBIs, and stolen bases are NOT included, since this project has no walk-rate, lineup-run-context, or stolen-base signal yet. Pitcher points model innings/strikeouts/walks allowed/hits allowed plus an estimated earned-run penalty (from FIP, not real ERA - see README for why); wins and complete-game/no-hitter bonuses are NOT included. See README for the full methodology, known limitations, and backtest numbers.

Backtested against real outcomes, reported honestly: the hitter ranking's real correlation with actual next-game results is essentially zero (-0.004) - treat it as unvalidated, not a reliable signal yet. Pitcher rankings show a real, if modest, positive signal (correlation ~0.31 combined, mainly from innings/strikeouts). See README for the full numbers.
