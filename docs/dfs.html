DFS Rankings

Predictive Metrics Age Curves DFS Rankings

Today's hitters and probable starting pitchers, ranked by estimated DraftKings Classic MLB fantasy points, plus an Optimal Lineup tab that builds a salary-cap-and-position-slot DraftKings Classic lineup on top of those projections. Hitter points model hit-type scoring only (singles/doubles/triples/home runs, adjusted for today's actual opposing pitcher) - walks, HBP, runs, RBIs, and stolen bases are NOT included, since this project has no walk-rate, lineup-run-context, or stolen-base signal yet. Pitcher points model innings/strikeouts/walks allowed/hits allowed plus an estimated earned-run penalty (from FIP, not real ERA - see README for why); wins and complete-game/no-hitter bonuses are NOT included. See README for the full methodology, known limitations, and backtest numbers.

Backtested against real outcomes, reported honestly: the original heuristic hitter ranking had essentially zero real correlation with actual next-game results (-0.004). A gradient-boosting model trained on the same underlying matchup ingredients (not the flawed heuristic formula) has since replaced it and now shows a real, if still modest, positive signal (correlation 0.145). Pitcher hits-allowed and walks projections were similarly upgraded via a validated regression model. None of these are strong signals yet - treat them as directionally useful, not high-confidence - but each one now beats both a naive guess and its own prior heuristic on real held-out data. See README for the full numbers and methodology.

Estimated_Salary is NOT a real DraftKings price. DraftKings has no public API for contest salaries, so this project cannot fetch real ones. Every dollar figure below is a MODELED estimate derived from this project's own point projections (see README's "Optimal Lineup" section for the exact formula) - it is not sourced from DraftKings in any way. Always verify the real price on DraftKings.com before entering any contest, and do not assume a lineup built here is a valid budget on the real platform.
