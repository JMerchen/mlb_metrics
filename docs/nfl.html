Team units

How strong each team's units are, on a scale where 100 is league average and higher is always stronger (like OPS+ or ERA+). Every 10 points is about one standard deviation: 110 is top-six territory, 120 is elite, 90 and 80 the same distance below. Each number is points added (or allowed) per play from the team's recent games, the latest weighted most. QB+ is the QB listed to start this week, so a backup starting shows up here. My Draft

Real, transparent signals for the pick you're at right now - your own real roster gap against real per-team targets, and each position's real necessity (Position Necessity above). This tool does NOT try to guess who's still on the board - it has no view of a live draft board, so it can't know what OTHER teams have taken. Instead, add the specific players YOU'RE weighing for this pick below and the table assesses each one: their real value above replacement, whether their position is a real roster need right now, and - once a draft slot + pick number are entered - a real reach/value read against their own real ECR +/- expert-rank standard deviation (a player with no real ECR match simply shows no read, not a fabricated one). Saved to this browser only (no account/server) - use "Clear My Draft" to reset.
