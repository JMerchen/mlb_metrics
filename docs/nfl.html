What if?

Swap a starting QB, mark players out, and set how well each unit plays. Each team's run game, pass game, run defense and pass defense are rated in percent of their normal yards per play (a defense at 90% allows 10% more). A player out lowers the units his position touches by a default - what an absence at that position has cost teams in results, scaled by how much he plays - and you can type over it for any player ("run game at 50% without him") or set a whole unit outright. The yards become points and the points become win chance, the same way Vegas turns point spreads into odds. A QB swap reruns our model with that QB's rating; "Average starter" and "an average regular" cover anyone not listed. Players follow their current roster. Last week's view replays the games with only what we knew before kickoff, so you can test your settings against how they finished.

Team units

How strong each team's units are, on a scale where 100 is league average and higher is always stronger (like OPS+ or ERA+). Every 30 points is about one standard deviation: 130 is top-six territory, 160 is elite, 70 and 40 the same distance below. Each number is points added (or allowed) per play. By default recent games count more (reaching back into last season) and each unit is adjusted for the strength of the opponents it has faced - the combination that best predicted the next game over 2017-2026; switch either off to see this season's games counted equally, or unadjusted. QB+ is the QB listed to start this week, so a backup starting shows up here. Tap a column to sort.

This week's matchups

Each game, with each offense's edge against the defense it faces. Passing differential: the average of the team's QB+ and Receiving+, minus the opponent's Pass D+. Rushing differential: its Rushing+ minus the opponent's Run D+. Higher is a friendlier matchup for that offense; +30 or more (green) is a gap of a standard deviation, −30 or less (red) the same the other way. Most lopsided games first.

Real, transparent signals for the pick you're at right now - your own real roster gap against real per-team targets, and each position's real necessity (Position Necessity above). This tool does NOT try to guess who's still on the board - it has no view of a live draft board, so it can't know what OTHER teams have taken. Instead, add the specific players YOU'RE weighing for this pick below and the table assesses each one: their real value above replacement, whether their position is a real roster need right now, and - once a draft slot + pick number are entered - a real reach/value read against their own real ECR +/- expert-rank standard deviation (a player with no real ECR match simply shows no read, not a fabricated one).
