Age Curves

← Back to MLB Metrics

Pick a current hitter or pitcher and a stat, and see how their season compares to historical players at the same age, and what a next season might look like based on what those comparable players actually did. Each metric gets its own comparable search - power, plate discipline, contact rate, and pitching components all age differently, so a single blended number would hide that. Pitcher metrics (K9/BB9/HR9/FIP) deliberately exclude ERA - see README for why. Exploratory, not a live prediction - built from Lahman's Baseball Database (1871-present), not this project's own Statcast-based models. No era/park adjustment - see README for details and known limitations.
